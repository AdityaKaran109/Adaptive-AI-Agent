## Procedure

1. Run `make proto` to generate the protobuf stubs.
2. Ensure `make proto` is executed after every pull or change.
3. Verify the `acme/orders` directory contains `order.proto` and generated `order_pb2.py`.
4. Run `python -m pip install -e .` to install the package in editable mode.
5. Confirm `order_pb2` is importable after both `make proto` and `pip install -e .`.

## Provenance

- **Run `make proto` to generate the protobuf stubs.** — All episodes report ImportError: cannot import name 'order_pb2' due to missing generated stubs. _(episodes: sess-001, sess-002, sess-003, sess-004, sess-005)_
- **Ensure `make proto` is executed after every pull or change.** — Fixes across episodes indicate the issue is not a missing dependency but a missing generation step. _(episodes: sess-001, sess-002, sess-003, sess-004, sess-005)_
- **Verify the `acme/orders` directory contains `order.proto` and generated `order_pb2.py`.** — The error consistently points to missing `order_pb2` module, which is generated by `make proto`. _(episodes: sess-001, sess-002, sess-003, sess-004, sess-005)_
- **Run `python -m pip install -e .` to install the package in editable mode.** — All episodes fail due to missing generated stubs, not missing dependencies. _(episodes: sess-001, sess-002, sess-003, sess-004, sess-005)_
- **Confirm `order_pb2` is importable after both `make proto` and `pip install -e .`.** — The root cause is the missing generated stubs, not the protobuf library itself. _(episodes: sess-001, sess-002, sess-003, sess-004, sess-005)_
